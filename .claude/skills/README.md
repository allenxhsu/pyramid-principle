# Vendored agent skills

Copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit
`c55ee46073ed923f86ce59a5eb3b6d895095d1b7` (the set shipped in its `mattpocock-skills`
plugin, v1.2.3). MIT licensed; see `LICENSE-mattpocock-skills`.

These are copied rather than installed as a plugin so they load in every Claude Code
surface (CLI, IDE, and cloud sessions). Don't also enable the `mattpocock-skills`
plugin, or every skill will appear twice.

To update, re-copy the folders listed in upstream `.claude-plugin/plugin.json` and bump
the commit above.
